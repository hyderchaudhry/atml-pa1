# ATML PA1
## External resources citation
Task 1 calls the [pytorch-AdaIN](https://github.com/naoto0804/pytorch-AdaIN) implementation and its published weights after installing from GitHub. The method is Huang and Belongie, *Arbitrary Style Transfer in Real-time with Adaptive Instance Normalization* (ICCV 2017), [arXiv:1703.06868](https://arxiv.org/abs/1703.06868).

 Task 4's PROSER section uses the loss described in 
Zhou et al. (2021). *Learning placeholders for open-set recognition*. Proceedings of the IEEE/CVF Conference on Computer Vision and Pattern Recognition (CVPR), 4401–4410.
